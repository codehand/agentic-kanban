# P0 — Scaffold & toolchain (+ adapt engine `.ai/` cho Node)

> Nguồn: `IMPLEMENTATION_PLAN.md` §5 (P0), §3 (tech stack đã chốt), §4 (nguyên tắc) ·
> `TASK_HUB_DESIGN.md` §2 (phạm vi & stack).

## Mục tiêu

Dự án **build / test / boot được** trên stack đã chốt và có thể chạy task qua workflow gate của chính
repo. Đặt nền (tooling + cấu trúc thư mục + config loader + health endpoint) để các phase lõi P1–P4 đứng
lên mà không phải sửa toolchain. Không có business rule trong P0.

## Phạm vi

In scope:
- Init **pnpm** workspace + `tsconfig` (ESM, Node ≥ 20) + eslint/prettier + **vitest**.
- Cấu trúc `server/src` theo `IMPLEMENTATION_PLAN.md` §3: `config/ db/ auth/ domain/ mcp/ api/ http/` + `test/`.
- Config loader: env `PORT`, `ADMIN_TOKEN`, `DB_PATH`; file `config.yml` (check modes/thresholds, lease TTL).
- Logger **pino** (structured); chưa log secret.
- `GET /healthz` trên **`node:http`** (không web framework) → `200 {"status":"ok"}`.
- Adapt engine `.ai/`: `config.yml` (`commands.build`→`pnpm build`, `commands.test`→`pnpm test`);
  `run-evidence.sh` build/test Node + coverage qua `vitest --coverage`, ghi `*.exit` + `manifest.json`,
  giữ contract export `AI_WT_<REPO>`.

Out of scope: data layer (P1), auth (P2), gate/state machine (P3), MCP/API (P5+).

## Module & file

- `package.json`, `pnpm-lock.yaml`, `tsconfig.json`, `.eslintrc` / `prettier` / `vitest.config.ts`.
- `server/src/config/index.ts` — load env + `config.yml`.
- `server/src/http/server.ts` — bootstrap `node:http`, route `/healthz`.
- `server/src/logger.ts` — pino instance.
- `.ai/config.yml`, `.ai/scripts/run-evidence.sh` — adapt cho Node (build/test/coverage).

## Task checklist

- [ ] Init pnpm + tsconfig (ESM) + eslint/prettier + vitest.
- [ ] Tạo cây thư mục `server/src/{config,db,auth,domain,mcp,api,http}` + `server/test`.
- [ ] Viết config loader (env + `config.yml`).
- [ ] Bootstrap `node:http` server + `GET /healthz`.
- [ ] Adapt `.ai/config.yml` (`pnpm build` / `pnpm test`) + `run-evidence.sh` (Node build/test/coverage, manifest).

## Acceptance criteria

- `pnpm install && pnpm build` → exit 0.
- `pnpm test` → exit 0 (kể cả khi 0 test).
- `curl /healthz` → `200 {"status":"ok"}`.
- `.ai/scripts/run-evidence.sh <task-id>` sinh `evidence/<task-id>/{build.exit,test.exit,manifest.json}` cho repo Node.
