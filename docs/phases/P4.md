# P4 — Evidence subsystem

> Nguồn: `IMPLEMENTATION_PLAN.md` §5 (P4) · `TASK_HUB_DESIGN.md` §7 (luồng evidence), §1.2 (evidence
> immutable), §6 (`evidence.submit`, `task.selfcheck`).

## Mục tiêu

"Evidence là sự thật do máy đo, immutable" — chống bịa. Chỉ role `runner` ghi; ghi xong khoá + checksum;
`task.selfcheck` đọc evidence mới nhất, verify checksum, chấm theo config rồi để **gate** đổi state.

## Phạm vi

In scope:
- `evidence.submit(...)` **runner-only** → ghi row immutable: `build_exit/test_exit/lint_exit/ac_exit`,
  `coverage_pct`, `manifest_json` (file→sha256), `logs_json`. Bản ghi mới = lần run mới.
- `task.selfcheck(key)`: đọc evidence **mới nhất** (theo created_at/id), verify checksum manifest,
  build/test/ac **hard-required**; lint/coverage theo config (optional→warn, required→block) → gọi
  **gate** set `SELF_CHECK_PASSED|FAILED`.
- Re-verify checksum tại transition judge (phối hợp guard P3).

Out of scope: ghi state trực tiếp (P4 gọi gate P3); chạy build/test (runner làm local, server không chạy).

## Module & file

- `server/src/domain/evidence.ts` — `submit()` (runner-only) + `selfcheck()`.
- `server/src/domain/checksum.ts` — verify `manifest_json` (file→sha256).
- dùng lại `server/src/domain/gate.ts` (P3) để set state từ selfcheck.

## Task checklist

- [ ] `evidence.submit` enforce role=runner; ghi row immutable + manifest + exit codes + coverage + logs.
- [ ] `selfcheck` đọc evidence mới nhất theo created_at/id (định nghĩa "latest" rõ ràng).
- [ ] Verify checksum manifest; lệch → reject.
- [ ] Chấm: build/test/ac hard-required; lint/coverage theo config (optional→warn, required→block).
- [ ] selfcheck gọi gate set SELF_CHECK_PASSED|FAILED.
- [ ] Test: role≠runner reject, no-update-path, pass/fail theo exit, tamper checksum, optional vs required.

## Acceptance criteria

- Submit bởi role ≠ runner → reject — test.
- Evidence không sửa được sau khi ghi (no update path) — test.
- `selfcheck`: build/test/ac = 0 → PASSED; bất kỳ ≠ 0 → FAILED — test.
- Manifest checksum lệch (giả lập tamper) → selfcheck/judge reject — test.
- lint/coverage: optional → warn (không chặn); đổi config required → chặn — test.

## Phụ thuộc & rủi ro

- **Phụ thuộc:** P1 (bảng evidence append-only), P2 (role runner), P3 (gate set state).

  quán; `manifest_json` đủ để tái-verify mà không ôm full log.
