## Mục tiêu

Chạy ổn định trên **LAN cho 1 operator**: error nhất quán, giới hạn input, structured logs, README/
runbook, backup SQLite, graceful shutdown, deploy unit, basic metrics. Đây là polish v1, không thêm
feature ngoài design.

## Phạm vi

In scope:
- Error response nhất quán (domain reject vs lỗi hệ thống) + giới hạn input (size/rate cơ bản).
- Structured logs (pino) cho mỗi transition (actor, from→to, evidence_ref) — `IMPLEMENTATION_PLAN.md` §7.
- README quickstart + runbook (chạy end-to-end trên máy sạch).
- Backup SQLite; graceful shutdown (đóng DB không hỏng file).
- systemd unit / container; basic metrics.
- UI a11y AA (kế thừa prototype) — Lighthouse.

Out of scope: TLS, RBAC đa-human, public-internet auth, auto-merge MR (`IMPLEMENTATION_PLAN.md` §10;
`TASK_HUB_DESIGN.md` §13).
