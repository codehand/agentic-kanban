# P6 — Concurrency: claim / lease / heartbeat

> Nguồn: `IMPLEMENTATION_PLAN.md` §5 (P6), §6 (song song P6/P7) · `TASK_HUB_DESIGN.md` §11 (claim/lease/
> heartbeat), §4 (`task.assignee_token_id`, `lease_until`).

## Mục tiêu

Nhiều agent đa-device **không giành** một task. Claim gắn assignee + lease; heartbeat gia hạn; release/
expiry mở lại; transition (non-human/gate) đòi caller giữ lease.

## Phạm vi

In scope:
- `task.claim(key)`: set `assignee_token_id` + `lease_until`, **chỉ khi** task chưa lease hoặc lease hết
  hạn; dùng transaction SQLite chống đua.
- `task.heartbeat(key)`: gia hạn `lease_until` (agent đang chạy gọi định kỳ).
- `task.release(key)`: nhả sớm. Lease hết hạn → task tự mở claim lại.
- Transition đòi caller **đang giữ lease** (trừ `human` / `gate`).
- TTL **15 phút**, heartbeat mỗi **5 phút** (cấu hình qua `config.yml`).

Out of scope: bản thân các tool đã mount ở P5 (đây là hoàn thiện semantics lease).

## Module & file

- `server/src/domain/lease.ts` — claim/heartbeat/release/expiry (transaction).
- cập nhật `server/src/domain/gate.ts` — guard "caller giữ lease" cho transition non-human.
- `server/src/config/index.ts` — lease TTL + heartbeat interval.

## Task checklist

- [ ] `claim` set assignee + lease_until chỉ khi tự do / hết hạn (transaction chống đua).
- [ ] `heartbeat` gia hạn lease_until.
- [ ] `release` nhả; expiry tự mở claim lại.
- [ ] Transition đòi lease (trừ human/gate).
- [ ] TTL 15m / heartbeat 5m từ config.
- [ ] Test: claim free ok, claim khi đang lease reject, claim sau expiry ok, transition không-lease reject.

## Acceptance criteria

- Claim khi task tự do → ok; token khác claim khi đang lease → reject — test.
- Sau khi lease hết hạn, token khác claim được — test.
- Transition bởi token không giữ lease (non-human) → reject — test.
