# P3 — State machine & Gate (lõi cưỡng chế)

> Nguồn: `IMPLEMENTATION_PLAN.md` §5 (P3), §4.3 (gate là trụ test) · `TASK_HUB_DESIGN.md` §5 (state
> machine + bảng transition), §1.1 (chỉ gate ghi state).

## Mục tiêu

Thực thể **duy nhất** ghi `state` + `transition` (append-only). Tái lập đúng `gate.sh`: cưỡng chế bảng
transition + role + guard + checksum. Đây là trụ chống false-positive completion.

## Phạm vi

In scope:
- Bảng `ALLOWED` (`FROM→TO:role`) **pure** đúng `TASK_HUB_DESIGN.md` §5:
  - `TODO→IN_PROGRESS:implementer`
  - `IN_PROGRESS→IMPLEMENTED:implementer`
  - `IMPLEMENTED→SELF_CHECK_PASSED|SELF_CHECK_FAILED:self-check`
  - `SELF_CHECK_FAILED→IN_PROGRESS:implementer`
  - `SELF_CHECK_PASSED→JUDGE_PASSED|JUDGE_REJECTED:judge`
  - `JUDGE_REJECTED→IN_PROGRESS:implementer`
  - `JUDGE_PASSED→DONE:human`
- `gate.propose`: validate state thực tế == `from`, transition hợp lệ, role đúng, **không nhảy cóc**.
- Guards:
  - **→IMPLEMENTED**: mỗi `gitref` có `head_sha != base_sha`, hoặc `allow_no_code_change`.
  - **→JUDGE_PASSED / →JUDGE_REJECTED**: đòi comment `kind=verdict` với `verdict` tương ứng tồn tại.
  - **→JUDGE_PASSED** (và selfcheck): re-verify checksum evidence (manifest_json).
  - **→DONE**: chỉ role `human`.
- Ghi `transition` append-only (actor_role/actor_token_id/at/note/evidence_id).

Out of scope: tự đọc evidence để chấm self-check (P4 gọi gate); concurrency lease guard (P6).

## Module & file

- `server/src/domain/gate.ts` — `propose()` validate + guard + checksum + ghi transition.

## Acceptance criteria

- Nhảy cóc (vd `IMPLEMENTED→JUDGE_PASSED`) → reject — test.
- Sai role → reject — test.
- `→IMPLEMENTED` khi không repo nào đổi & không `allow_no_code_change` → reject; có flag → pass — test.
- `→JUDGE_PASSED` thiếu comment verdict=PASS → reject — test.
- `→DONE` bởi non-human → reject — test.
